\subsection{Projet : Développement d'une plateforme intelligente de suivi des livraisons en temps réel}

\cvitem{Contexte}{%
  Le secteur logistique nécessite des outils performants pour le suivi des expéditions et le respect des délais de livraison. Ce stage a consisté à concevoir et développer une application web complète pour les entreprises de logistique.}

\cvitem{Réalisations}{%
  \begin{itemize}\itemsep0.2em
    \item Suivi en temps réel des colis avec traçabilité complète des livraisons
    \item Optimisation de l'ordre des livraisons pour chaque livreur (réduction des temps de tournée)
    \item Système de notifications automatiques en cas de retard ou d'incident
    \item Amélioration de la relation client grâce à une meilleure visibilité des expéditions
  \end{itemize}}

\cvitem{Stack technique}{Java / Spring Boot · React / JavaScript · MySQL · API REST · Git \& GitHub}
